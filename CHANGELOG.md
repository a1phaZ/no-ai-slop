# Changelog

Все заметные изменения проекта. Формат — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено
- Нейросетевой детектор MLP (20 → 16 → 1) и режим «Линейная модель»; фолбэк
  NN → линейная → эвристики.
- `npm run eval`: отчёт по test и реальным меткам — Brier/ECE, срезы по языку,
  источнику и длине, sweep порога, топ ошибок.
- Импорт меток в обучение: `import-labels --mode=train` после ~200 меток,
  `build-dataset` подхватывает `data/raw/user.jsonl`, дедуп и `sample_weight`.
- Карточка активной модели и разбивка меток (ИИ/человек, языки, согласие с порогом)
  в настройках.
- Публичный EN+RU датасет без ключей: `import-public.mjs --coat` (CoAT/RuATD) и
  `--semeval` (SemEval-2024 Task 8), плюс `--out`, `--offset` и retry на 429.
- `fetch-human.mjs`: часовые окна, `--limit`, `--max-windows`, `--out`; link-only
  посты и URL-мусор отбрасываются до обучения.
- `build-dataset.mjs`: группировка HC3 по `prompt_id` (вопрос и ответы не
  разъезжаются по сплитам) и фильтр текста без body.
- `evaluate.mjs --all`: оценка всего внешнего набора (CoAT validation, SemEval test)
  без случайного test-сплита.

### Изменено
- Размытие и скрытие применяются к телу поста, а не к заголовку. У link/image-постов
  скрывается медиа-превью или миниатюра; если скрывать нечего, пост остаётся видимым
  и не попадает в счётчик скрытых.
- `SPEC.md`: актуализированы статус, scope и раздел «Фазы» (роадмап); порог
  по умолчанию исправлен на 0.55.
- Калибровка: temperature scaling вместо сдвига bias, precision-first порог
  (`--min-precision`, по умолчанию 0.9).
- Кэш инвалидируется при смене модели (`nn@N`/`linear@N`/`heuristic@N`).
- Датасет теперь public-first: HC3 + CoAT/SemEval — основной путь, Reddit и
  Ollama — опциональные источники доменного совпадения; метки пользователей
  больше не блокируют Phase 2.

## [0.4.0] - 2026-10-19

### Добавлено
- Сбор меток для датасета: кнопки **«Похоже на ИИ»** и **«Похоже, человек»** на каждом посту.
  Повторный клик снимает метку, кнопки взаимоисключающие.
- Локальное хранилище меток (до 2000 записей): текст, заголовок, оценка детектора,
  версии детектора и модели, язык, длина, время.
- Настройки → «Разметка для датасета»: счётчик с прогрессом, экспорт JSONL,
  импорт с мерджем по хэшу, очистка. Предупреждение на 80% и блокировка на 100%.
- Офлайн-пайплайн датасета (`training/`): `fetch-human.mjs` (arctic-shift, посты до 11.2022),
  `import-public.mjs` (HC3), `generate-ai.mjs` (Ollama), `dedup.mjs` (SimHash),
  `build-dataset.mjs` (групповые сплиты), `import-labels.mjs`, `README.md`.
- `train.mjs` читает `data/dataset.jsonl`, печатает метрики **по срезам**
  (язык, длина, источник) и калибровку (Brier/ECE).

### Изменено
- Метки «человек» больше не скрываются, метки «ИИ» скрываются мягче.
- Popup: счётчик «размечено» вместо «вручную»; точка на иконке — есть любая разметка.
- `PRIVACY.md`: описано локальное хранение текста размеченных постов и ручной экспорт.

## [0.3.0] - 2026-10-19

### Добавлено
- Сменный детектор: обученная модель (логистическая регрессия) с фолбэком на эвристики
  (`src/detector/index.ts`, `detect()`).
- Признаки вынесены в `src/detector/features.ts`, вектор признаков — `src/detector/vector.ts`.
- Модель и веса: `src/detector/model.ts`, `src/detector/weights.ts` (автогенерация).
- Скрипт обучения `training/train.mjs` и seed-датасет `training/dataset.jsonl` (120 примеров).
- Выбор в настройках: **Детектор** — «Модель» или «Эвристики».
- В debug-лог добавлен источник (`[model]`/`[heuristic]`) и сработавшие признаки.

### Изменено
- `DETECTOR_VERSION` 2 → 3 (кэш инвалидируется автоматически).
- Тесты: `tests/model.test.ts`, `tests/detect.test.ts`; всего 40 тестов.

## [0.2.1] - 2026-10-19

### Добавлено
- Иконки расширения 16/32/48/128 и `scripts/gen-icons.mjs` (генерация PNG без зависимостей).
- CI (`.github/workflows/ci.yml`): typecheck, тесты, сборка, артефакт `dist/`.
- Release-workflow (`.github/workflows/release.yml`): сборка `.zip` по тегу `v*`.
- `scripts/package.mjs` + `npm run package` — сборка `.zip` для Chrome Web Store.
- DOM-тесты content-слоя (`happy-dom`): `tests/reddit.test.ts`, `tests/ui.test.ts`.
- Документы: `LICENSE` (MIT), `CHANGELOG.md`, `PRIVACY.md`.

## [0.2.0] - 2026-10-19

### Добавлено
- Контрол с оценкой **AI ~NN%** и кнопкой **«Возможно AI»** на каждом посте.
- Счётчик «проверено» в popup; лог `[no-ai-slop]` при включённом debug.
- Фолбэки селекторов для нового и старого интерфейса Reddit.
- Обработка ошибок инициализации (фолбэк на настройки по умолчанию).

### Изменено
- Перекалиброван детектор: признаки применяются к короткому тексту, порог по умолчанию 0.6 → 0.55.
- `DETECTOR_VERSION` 1 → 2 (старый кэш инвалидируется автоматически).

## [0.1.0] - 2026-10-19

### Добавлено
- Chrome MV3 расширение: локальная детекция AI-постов на Reddit (EN + RU).
- Эвристики: шаблонные фразы, ритм предложений, пунктуация, сокращения, длинное тире, списки.
- Локальный кэш проверок, счётчики и badge, popup и страница настроек.
