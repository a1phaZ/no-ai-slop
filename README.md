# no-ai-slop

Chrome-расширение, которое скрывает посты, сгенерированные ИИ, в ленте Reddit.

Проверка и результат держатся **локально**: текст не покидает браузер.

## Возможности

- Локальная оценка «AI-вероятность» (0..1) по тексту поста (EN + RU).
- **Сменный детектор**: обученная модель (логистическая регрессия) или эвристики.
- Порог уверенности задаёт пользователь (по умолчанию 0.55).
- Два режима: **заблюрить** (с кнопкой «Показать») или **скрыть**.
- Оценка `AI ~NN%` и две кнопки разметки — **«Похоже на ИИ»** / **«Похоже, человек»** —
  на каждом посте.
- Счётчик скрытых постов на иконке; точка — есть разметка.
- Кэш проверок, чтобы один и тот же текст не проверялся повторно.
- **Локальный сбор меток** для датасета: экспорт/импорт JSONL в настройках.

## Детектор

Два режима (настройки → **Детектор**):

- **Модель** — логистическая регрессия над 20 признаками (`src/detector/vector.ts`),
  веса в `src/detector/weights.ts`. Если модель недоступна или падает — автоматический
  фолбэк на эвристики.
- **Эвристики** — интерпретируемые правила (`src/detector/heuristics.ts`): шаблонные фразы,
  ритм предложений, пунктуация, сокращения, длинное тире, списки.

Переобучение:

```bash
npm run train     # training/train.mjs -> src/detector/weights.ts
```

`train.mjs` читает `data/dataset.jsonl` (собранный набор), а если его нет —
seed-датасет `training/dataset.jsonl`. Делит данные по заданным сплитам (или 60/20/20),
стандартизует признаки, обучает модель с L2-регуляризацией, подбирает порог
по валидации и печатает метрики **по срезам** + калибровку (Brier/ECE).

## Сбор меток пользователей

Кнопки под постом сохраняют **локально** текст, заголовок, оценку детектора,
версии модели и время. Ничего не отправляется автоматически.

- Настройки → «Разметка для датасета»: счётчик, экспорт JSONL, импорт, очистка.
- Лимит — 2000 меток (~2.4 МБ); при достижении новые не пишутся, пока не сделаете экспорт.
- Экспорт → `no-ai-slop-labels-YYYYMMDD.jsonl`.

Как метки попадают в обучение — см. [`training/README.md`](training/README.md).

## Датасет

Полный пайплайн (реальные посты Reddit до 11.2022, HC3, генерация через Ollama,
дедуп, групповые сплиты) описан в [`training/README.md`](training/README.md).

```bash
npm run data:human   # arctic-shift, без ключей
npm run data:public  # HC3 reddit_eli5
npm run data:ai      # Ollama, локально
npm run data:dedup
npm run data:build
npm run train
```

Сырые данные лежат в `data/` и **не коммитятся**. Честное предупреждение:
seed-датасет (120 примеров) даёт завышенные метрики; реальное качество
появится только на собранном наборе и метках пользователей.

## Установка

Готовый `.zip` — в [Releases](https://github.com/a1phaZ/no-ai-slop/releases).
Локально: собрать (`npm run build`) и загрузить папку `dist/` через
`chrome://extensions` → «Загрузить распакованное».

## Разработка

Требуется Node.js ≥ 22.

```bash
npm install
npm run build      # собрать расширение в dist/
npm run watch      # пересборка на изменениях
npm test           # юнит- и DOM-тесты
npm run typecheck  # проверка типов
npm run package    # no-ai-slop-<version>.zip для Chrome Web Store
npm run icons      # перегенерировать иконки (src/icons/*.png)
npm run train      # переобучить модель (training/train.mjs)
npm run data:human # собрать человеческие посты (arctic-shift)
npm run data:public # импортировать HC3
npm run data:ai    # сгенерировать AI-посты (Ollama)
npm run data:dedup # точный и почти-точный дедуп
npm run data:build # баланс и групповые сплиты
```

## Структура

- `src/detector/` — детектор: признаки, вектор, модель, эвристики, кэш (без `chrome`).
- `src/content/` — извлечение постов и применение решения.
- `src/background.ts` — счётчики и badge.
- `src/popup/`, `src/options/` — интерфейс.
- `src/icons/` — иконки (генерируются `scripts/gen-icons.mjs`).
- `scripts/` — сборка (`build.mjs`), упаковка (`package.mjs`), иконки, ZIP-писатель.
- `training/` — датасет, пайплайн сбора и обучение модели.
- `SPEC.md` — спецификация; `CHANGELOG.md` — история версий.

## CI/CD

- `ci.yml` — на push/PR в `main`: typecheck, тесты, сборка, артефакт `dist/`.
- `release.yml` — по тегу `v*`: сборка `.zip` и публикация в GitHub Release.

## Приватность

Никаких сетевых запросов. Настройки — в `storage.sync`, кэш, счётчики и метки —
в `storage.local`. Метки выносятся из браузера только вручную (экспорт JSONL).
Подробнее — в [PRIVACY.md](PRIVACY.md).
