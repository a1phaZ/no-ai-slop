# SPEC — no-ai-slop

Chrome-расширение, которое скрывает сгенерированный ИИ контент (посты) на Reddit.

Статус: **Phase 1 — сделано, Phase 2 — в работе (0.4.0)**
Дата: 2026-10-28
Распространение: Chrome Web Store (MV3).

---

## 1. Цель

Дать читателю Reddit возможность не видеть посты, написанные ИИ, не покидая
ленту и без отправки текста на сторонние серверы. Проверка и результат
хранятся локально.

## 2. Scope

**Входит (сделано):**
- Chrome, Manifest V3.
- Площадка: **Reddit** (новый интерфейс `shreddit-*` и старый `old.reddit.com`).
- Объект: **только посты** (не комментарии).
- Анализ: **только текст** (заголовок + тело поста). Изображения/видео не анализируются.
- Языки: английский и русский (одна модель признаков для обоих).
- Детекция: **полностью локально**, результат кладётся в локальный кэш.
- UI: порог уверенности задаёт пользователь; режимы **заблюрить** (с кнопкой «Показать»)
  или **полностью скрыть**; счётчик скрытого на иконке расширения.
- Ручные метки **«Похоже на ИИ» / «Похоже, человек»** на посте.

**Не входит (отложено):**
- Сервер/сеть, общий кэш между пользователями — Phase 3.
- Комментарии, другие сайты, Firefox — Phase 4.
- Крупные нейросетевые модели (ONNX/эмбеддинги) — вне Phase 2; сейчас MLP на признаках.

## 3. Функциональные требования

- **FR-1 Сканирование.** На страницах Reddit находить посты и применять решение
  к каждому по мере появления (в т.ч. при бесконечной прокрутке).
- **FR-2 Локальная детекция.** Считать оценку «AI-вероятность» 0..1 по тексту
  поста. Один и тот же текст проверяется один раз; далее — из кэша.
- **FR-3 Кэш.** Ключ — хэш текста. Значение: оценка, время, версия детектора.
  Версия детектора инвалидирует старые записи.
- **FR-4 Порог.** Пользователь задаёт порог (0..1, по умолчанию 0.55). Пост
  скрывается, если оценка ≥ порога и есть что скрывать (тело или медиа-превью).
- **FR-5 Режим отображения.** `blur` — размытие тела поста + кнопка «Показать»;
  `hide` — полное скрытие тела + кнопка «Показать». Заголовок остаётся видимым
  всегда. У link/image-постов вместо тела скрывается медиа-превью или миниатюра;
  если скрывать нечего — пост остаётся видимым, плашка с оценкой сохраняется.
- **FR-6 Ручная разметка.** Кнопки «Похоже на ИИ» / «Похоже, человек» на посте.
  «ИИ» понижает порог (скрывать увереннее), «человек» — повышает (показывать).
  Разметка учитывается отдельным индикатором.
- **FR-7 Счётчик.** На иконке: **основное число — сколько постов скрыто**;
  **точка-индикатор** — есть ручные метки.
- **FR-8 Настройки.** Вкл/выкл, режим, детектор (NN / линейная / эвристики),
  порог, сканировать ли old.reddit, сброс счётчиков.
- **FR-9 Не трогать.** Если расширение выключено — никаких изменений в DOM и
  счётчиках.

## 4. UX

- **Иконка (badge).** Белый текст на цветном фоне; число = скрытые; при наличии
  ручных меток к числу добавляется `•`. Фон — нейтральный, при ручных метках —
  акцентный.
- **Оверлей скрытого поста.** Скрывается только тело (или медиа-превью у
  link/image-постов), заголовок остаётся читаемым. Кнопки: «Показать»,
  «Похоже на ИИ», «Похоже, человек».
- **Popup.** Счётчик скрытых/ручных, тумблер вкл/выкл, выбор режима, слайдер
  порога, кнопка «Сбросить счётчики», ссылка на настройки.
- **Options.** То же + расширенные флаги (debug, old.reddit).

## 5. Детекция

Три режима: нейросеть MLP (по умолчанию), линейная логистическая регрессия и
эвристики. При ошибке модели — автоматический фолбэк NN → линейная → эвристики.
Оценка — сигмоида от взвешенной суммы признаков (см. `src/detector/`), вероятность
калибруется temperature scaling, порог выбирается precision-first на валидации.

Признаки-«ИИ»:
- маркеры-шаблоны EN/RU («in today's fast-paced world», «delve into»,
  «it's important to note», «в современном мире», «важно отметить», «играет
  важную роль» и т.п.);
- высокая плотность длинного тире (—);
- низкая доля сокращений (EN) при длинном тексте;
- низкая «бурстность» (равномерная длина предложений);
- идеальная пунктуация/капитализация;
- структура списков с жирными лид-инами;
- равномерные «средние» предложения, отсутствие коротких рубленых фраз.

Признаки-«человек» (понижают оценку):
- разговорные маркеры (lol, tbh, imo, бли\n, хз, короч…), опечатки-растяжки,
  сленг, ненормативная лексика.

Точное совпадение вида «as an AI / как ИИ» → мгновенная метка.

## 6. Хранилище

- `chrome.storage.sync` — настройки (переносятся между устройствами).
- `chrome.storage.local` — кэш проверок и счётчики.
- Кэш ограничен LRU-размером (по умолчанию 2000 записей) и хранит id модели,
  поэтому переобучение инвалидирует старые оценки.

## 7. Архитектура

```
content script (Reddit DOM)
  ├─ collectPosts()        извлечение постов
  ├─ detect()              детектор: NN → линейная → эвристики
  ├─ cache (storage.local) одна проверка на текст + id модели
  └─ apply()               blur/hide тела + плашка + метки
        │ chrome.runtime.sendMessage
        ▼
service worker (background.ts)
  ├─ счётчики (storage.local)
  └─ badge на иконке
popup / options  ── storage.sync настройки + запрос счётчиков
```

## 8. Нефункциональные требования

- MV3, без удалённого кода: весь код в бандле.
- Никаких сетевых запросов в Phase 1–2 (сеть — только Phase 3, opt-in).
- Стабильность к изменениям DOM Reddit: несколько селекторов + фолбэки.
- Производительность: проверка одного поста — синхронная, без блокировки ленты.

## 9. Фазы

Единый источник планов — этот раздел; отдельного `ROADMAP.md` нет.

### Phase 1 — база (сделано)

- Интерфейс: плашка с оценкой, режимы blur/hide, кнопка «Показать».
- Локальная детекция на эвристиках, кэш проверок.
- Badge со счётчиком скрытых, ручная метка, popup и настройки.

### Phase 2 — детектор и данные (в работе)

Сделано:
- Сменный детектор: MLP (20 → 16 → 1) и линейная модель с фолбэком на эвристики,
  переобучение (`npm run train`, `npm run train:nn`).
- Калибровка: temperature scaling, precision-first порог, Brier/ECE в отчётах.
- Оценка: `npm run eval` — test + реальные метки, срезы, sweep порога, топ ошибок.
- Сбор меток: две кнопки разметки, локальное хранилище, экспорт/импорт JSONL.
- Импорт меток в обучение после ~200 штук: `--mode=train`, групповые сплиты,
  дедуп и `sample_weight`.
- Офлайн-пайплайн датасета: arctic-shift, HC3, Ollama, дедуп, групповые сплиты.
- Кэш инвалидируется при смене модели (`nn@N`/`linear@N`/`heuristic@N`).
- Статистика разметки и карточка модели в настройках.

Осталось:
- Накопить реальные метки (≥200) и переобучить на них.
- Проверить калибровку и порог на реальных данных, при необходимости — порог по языку.
- Решить по коротким текстам (link/image-посты): минимальная длина или отдельный порог.

### Phase 3 — сеть (запланировано)

- Общий кэш и opt-in выгрузка меток между пользователями (по умолчанию выключено).
- Требует бэкенда и обновления `PRIVACY.md`.

### Phase 4 — охват (запланировано)

- Комментарии, другие сайты, Firefox.

### Phase 5 — UX/продукт (запланировано)

- Whitelist, локализация интерфейса, расширенная статистика.
